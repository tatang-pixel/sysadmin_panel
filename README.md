SysAdmin Panel 🚀
Dashboard monitoring server lokal berbasis Node.js yang dirancang khusus untuk latihan infrastruktur home lab dan manajemen sistem.
🛠️ Fitur Utama
Real-time Monitoring: Memantau status sistem menggunakan script backend Node.js.
Lightweight Dashboard: Antarmuka HTML/CSS yang bersih dan responsif.
Log Management: Sistem pencatatan aktivitas server lokal.
⚙️ Cara Instalasi & Menjalankan di Lokal
Clone Repository ini:
git clone https://github.com/tatang-pixel/sysadmin_panel.git
Masuk ke Direktori Project:
cd sysadmin_panel
Install Dependencies:
npm install
Jalankan Server:
node server.js
Akses di Browser:
Buka http://localhost:3000 (atau sesuaikan port yang aktif).
